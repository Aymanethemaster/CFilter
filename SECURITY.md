# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability, memory safety issue, or buffer overflow risk within CFilter:

1. Please do not open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the maintainer at [Aymanethemaster](https://github.com/Aymanethemaster).
3. Include details on the affected image format, input sample, and reproduction steps.

We take memory safety and input validation seriously and will address valid reports promptly.
